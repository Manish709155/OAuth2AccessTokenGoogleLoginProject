1.What is OAuth 2.0?

It is authorization framework which allows a third-party application
to securely access user's resources from an authorization server
without sharing user's credentials.


----------- OAuth 2.0 Mechanism ---------

. Instead of credentials, share an access token.

. This process involves a lot of steps and complete OAuth  2.0 flow has to be followed.

Key Point: Password कभी भी आपकी Spring Boot application तक नहीं पहुँचता। Application केवल Access Token का उपयोग करके APIs access करती है।


------------------ Important Definition ----

client_id:
A unique identifier assigned by the Authorization Server to identify the client application.

redirect_uri:
The callback URL where the Authorization Server sends the authorization code after successful authentication.

scope:
Defines the permissions or resources that the client application is requesting access to on behalf of the user.

response_type:
Specifies the type of response the client expects from the Authorization Server, such as an authorization code.

state:
A random value generated by the client and returned by the Authorization Server to prevent CSRF attacks and maintain request integrity.



----------------- why do we need Auth Code ? -----------

. Access Token might become accessible if sent directly in the browser.


. Authorization Code is sent in the Callback API and the rest of the process takes place via the Backend serever

. Fetch Token API requires client secret as well alongside the Auth Code, and client secret is saved at Backend.
